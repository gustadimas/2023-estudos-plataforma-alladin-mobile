# Estudos de plataforma e Alladin

Isso é de mar/2023 a set/2023, da época da faculdade. Coloquei no GitHub em 2026 como registro e deixei como estava.

Projeto de estudo que fui usando durante 2023. A parte mais antiga tem testes de plataforma: ponte, plataforma móvel, arma, moedas e um inimigo que anda.

Em setembro coloquei aqui a atividade 1 de mobile, o Alladin. Você toca na tela pra atirar maçãs nos vasos que passam; cada vaso acertado vale ponto, e o jogo tem vidas, limite de tiros e tempo. Os scripts dele estão em `Assets/Scripts/Alladin`.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.18f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
